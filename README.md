# Friday Night Funkin' VR — QT Mod Port

Port no oficial hecho por fans del famoso mod **VS. QT Mod** de *Friday Night Funkin'* llevado a **Friday Night Funkin' VR (FNFVR)**, tomando como base el repositorio **[VS-Marshy-VR](https://github.com/memeee310/VS-Marshy-VR)** y el código/recursos del **[QT Mod original](https://github.com/Hazardous2468/QT-mod)**.

> [!NOTE]
> Este proyecto es un **fork en desarrollo** cuyo objetivo es adaptar la experiencia completa de *VS. QT* (canciones, personajes, escenarios y mecánicas características) al entorno de Realidad Virtual de FNFVR en **Godot Engine**.

---

## ¿Qué es esto?

**Friday Night Funkin' VR (FNFVR)** es un port independiente en Realidad Virtual de *Friday Night Funkin'* construido desde cero en **[Godot Engine](https://godotengine.org/)**, utilizando plugins de código abierto para dar soporte tanto a **PCVR** como a **Meta Quest (standalone)**.

Este repositorio adapta esa base (junto con las modificaciones de **VS-Marshy-VR**) para traer al universo VR el mod **VS. QT**, creado originalmente por **Hazardous24 (Hazard2468)** y **CountNightshade**.

---

## Contenido del QT Mod a adaptar

* **Historia principal:**
  * *Carefree*
  * *Careless*
  * *Censory-Overload*
* **Canciones extra y secretas:**
  * *Termination* (con su icónica mecánica de sierras mecánicas adaptada para esquivar en VR)
  * *Cessation*
  * *Interlope*
* **Jugabilidad en Realidad Virtual:**
  * Golpea las notas con tus manos en un formato 3D frente a QT y KB.
  * Zona de notas (*step zone*) ajustable a tu comodidad.
  * Mecánicas exclusivas de VR y eventos asíncronos heredados del motor de FNFVR.
